# Smart Tip & Bill Splitter

## Problem
Ask for a bill, tip percentage, and number of people, then print each person's share.

## How to run
    python main.py

## Example output

    Please enter a valid number

    Enter tip percentage:1
    Number of people:9.7
    Please enter a valid number
    Number of people:9
    DONE!

    Total amount: 70700.0
    Total tip: 700.0
    Each person's share: 7855.56
